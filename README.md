# 約100穣分の1 — 名もなき、いのち。

「80億分の1」に着想を得た、非公式の転生パロディゲーム。地球の原核生物に生まれ、その一生を短い文章で読みます。

## 起動と公開

依存パッケージ・ビルド・バックエンドは不要です。このディレクトリを任意の静的ホスティングに配置してください。`index.html`、`style.css`、`main.js` の3ファイルで動作します。サブディレクトリへの配置にも対応しています。

ローカルでは `python3 -m http.server 8000` を実行し、http://localhost:8000 を開いてください。JavaScript modulesを使用するため、ファイルの直接起動ではなくHTTPで配信してください。

外部フォント・画像・API・解析・ストレージは使いません。明朝体は端末のシステムフォントを使用します。コピー機能が利用できない環境では、選択してコピーするためのテキスト欄を表示します。

## 抽選モデル

個体数の代わりに原核生物の推定細胞数を使用し、陸の地下・海底堆積物・土壌・海水を400:300:260:120で抽選します。全生物の厳密な抽選ではなく、微生物優勢の状況を表す簡易モデルです。種別抽選は行わず、非原核生物・ウイルスは抽選から省略しています。毎回独立の抽選で、結末を均等に選びます。文章と時間は創作です。

数値の根拠・モデルの制約・論文へのリンクはゲーム内「抽選のしくみと、出典」を参照してください。
